# FOIA-06: Targeted Vendor and Transaction Follow-Up (Template)

## Purpose

Request records for specific transactions, vendors, or issues identified during the analysis of FOIA-01 through FOIA-05 responses.

## When to Use

This request should be completed **only after** transaction review identifies specific:

- Dates and amounts of questionable transactions
- Vendors with unusual purchasing patterns
- Missing receipts or invoices
- Unexplained transfers
- Questionable reimbursements
- Duplicate transactions
- Amounts inconsistent with library operations

## Request Structure

The request should be narrow and transaction-specific, following this pattern:

---

**Subject:** Freedom of Information Request - Targeted Records (Transaction Details)

**Request Body:**

Pursuant to the Arkansas Freedom of Information Act, Ark. Code Ann. § 25-19-101 et seq., I request the following records:

**[TRANSACTION 1]**

1. All records relating to [transaction description], including:
   - Invoice(s) from [vendor name] dated [date(s)]
   - Receipt(s) for order/transaction # [order number]
   - Purchase order or authorization
   - Documentation of approval
   - Bank or credit card statement showing payment
   - Correspondence relating to this purchase

**[TRANSACTION 2]**

2. All records relating to [transaction description], including:
   - [Specific documents]

**[VENDOR HISTORY]**

3. All purchase orders, receipts, and invoices for [vendor name] for the period [date range]

---

## Template Sections

### Missing Receipt Requests

If FOIA-02 revealed credit card charges without itemized receipts:

> All records relating to the charge of $[amount] to [cardholder's card] on [date] at [merchant/vendor], including the itemized receipt, invoice, and documentation showing what was purchased and how the expense was authorized.

### Unexplained Transfer Requests

If FOIA-01 or FOIA-04 revealed transfers without documentation:

> All documentation relating to the transfer of $[amount] from [fund/account] to [fund/account] on [date], including the authorization, approval, and explanation for the transfer.

### Duplicate Transaction Requests

If FOIA-02 or FOIA-03 revealed potential duplicate charges:

> All records explaining the following two apparently identical transactions:
> - [Date, amount, description 1]
> - [Date, amount, description 2]
> 
> Please explain whether one of these represents a duplicate charge, refund, or cancellation.

### Vendor History Requests

If FOIA-02 revealed unusual patterns with a particular vendor:

> All purchase orders, receipts, invoices, and payment records for [vendor name] for the period [date range], in order to review the complete transaction history with this vendor.

### Missing Documentation Requests

If FOIA-02 or FOIA-05 identified approval authority or documentation issues:

> For the purchase order/transaction dated [date] for $[amount] from [vendor]:
> - Purchase authorization or approval form showing who approved the purchase
> - Documentation showing the approver had authority to approve the amount
> - Any Board approval or exception documentation if required

### Reimbursement Follow-Up

If FOIA-02 revealed reimbursement issues:

> All documentation relating to the reimbursement request submitted by [employee/board member] on [date] for $[amount], including:
> - The original expense report
> - All supporting receipts and invoices
> - Approval documentation
> - Records showing when payment was made and by what method

## Key Questions to Answer

Before drafting FOIA-06 follow-ups, ask:

1. **Is the transaction clear or unclear?** If unclear, what specific clarification is needed?
2. **Is the documentation complete?** What documents are missing?
3. **Is the approval documented?** Does authorization evidence exist?
4. **Is the amount reasonable?** Is there an explanation for the amount?
5. **Is the vendor legitimate?** Are there concerns about the vendor?
6. **Is the timing correct?** Are deposits or payments timely?
7. **Is the pattern normal?** Is this a one-time issue or part of a pattern?

## FOIA-06 Should NOT Include

- Speculation or accusations of misconduct
- Requests for investigative information
- Requests to create new records or analyses
- Requests for personnel files or private information
- Assumptions of guilt

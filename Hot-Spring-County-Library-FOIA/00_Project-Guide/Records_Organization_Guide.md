# Records Organization and Analysis Guide

## When Records Arrive

### Step 1: Log Receipt

Update the FOIA Tracking Sheet:
- Record date received
- Note if complete or partial
- Record any fees
- Note any exemptions claimed
- Document any delays or issues

### Step 2: Initial Review

1. **Count documents:** How many pages/files?
2. **Identify types:** What documents are included?
3. **Check completeness:** Does it match the request?
4. **Note gaps:** What was not provided?
5. **Review exemptions:** What was withheld and why?

### Step 3: Organize Received Documents

Create subdirectories in the FOIA folder:
- `Incoming-Records/Original-Received/` — Keep originals as received
- `Incoming-Records/Sorted-by-Type/` — Organize by document type
- `Incoming-Records/Sorted-by-Date/` — Organize chronologically

### Step 4: Create Index

For each FOIA request, maintain an index:

## Data Entry into Analysis Sheets

### Evidence Log

As you review documents, populate the Evidence Log:

- **Evidence ID:** E-FOIA01-001, E-FOIA02-042, etc.
- **Date:** When the document was created/received
- **Source:** Which FOIA request?
- **File Name:** Original document name
- **Transaction Date:** Date of the transaction (if applicable)
- **Vendor:** If it's a payment
- **Amount:** Dollar amount
- **Account/Fund:** Which fund/account?
- **Payment Method:** Card, check, cash, etc.
- **Issue/Observation:** Any discrepancy or note

### Transaction Review Sheet

For each transaction in FOIA-02 or FOIA-03:

- **Transaction Date:** When it occurred
- **Vendor:** Who was paid
- **Description:** What was purchased or why was it received
- **Amount:** Dollar amount
- **Account/Fund:** Which fund/account
- **Card/Check:** Payment method
- **Receipt Present?** Yes/No/Partial
- **Invoice Present?** Yes/No
- **Ledger Entry?** Yes/No/Not found
- **Bank Payment?** Confirmed in bank statement?
- **Board Approval?** Is there evidence of board approval?
- **Asset Inventory Match?** If an asset purchase, is it in inventory?
- **Refund/Credit?** If applicable
- **Shipping Address:** Where was it delivered?
- **Related Employee/Board?** Any connection?
- **Notes:** Any concerns

## Key Analysis Tasks

### Task 1: Match Receipts to Statements

For each credit card statement:
- [ ] Obtain all itemized receipts
- [ ] Match receipt amount to statement amount
- [ ] Check that all dates align
- [ ] Verify merchant/vendor matches
- [ ] Note any missing receipts

### Task 2: Match Statements to Ledger

For all card and check payments:
- [ ] Locate corresponding ledger entry
- [ ] Verify amount matches
- [ ] Check account coding is correct
- [ ] Note any discrepancies

### Task 3: Match Ledger to Bank Statement

For all expenditures:
- [ ] Confirm payment cleared the bank
- [ ] Check payment date vs. processing date
- [ ] Note any delays
- [ ] Verify amount matches

### Task 4: Verify Deposits

For all cash and revenue:
- [ ] Match cash log to deposit slip
- [ ] Verify deposit amount to bank statement
- [ ] Confirm recording in revenue ledger
- [ ] Note any timing issues or variances

### Task 5: Check Approvals

For all significant transactions:
- [ ] Is there a purchase order?
- [ ] Is there an approval signature?
- [ ] Does amount fit within approval authority?
- [ ] Is there board meeting documentation?

### Task 6: Reconcile Accounts

For each fund and account:
- [ ] Obtain opening balance
- [ ] Sum all deposits/contributions
- [ ] Sum all expenditures/withdrawals
- [ ] Sum all transfers (in and out)
- [ ] Calculate expected ending balance
- [ ] Compare to actual ending balance
- [ ] Explain any variance

## Flagging Issues

As you analyze, flag items for follow-up:

### Red Flag Categories

1. **Missing Documentation**
   - Card charge without receipt
   - Payment without approval documentation
   - Reimbursement without supporting receipt

2. **Amount Discrepancies**
   - Receipt amount doesn't match statement amount
   - Deposit doesn't match cash log
   - Ledger entry different from bank statement

3. **Approval Issues**
   - Large purchase without documented approval
   - Amount exceeds cardholder authority
   - No board approval for significant spending

4. **Timing Issues**
   - Delayed deposits (more than 3-5 days)
   - Missing statements for certain months
   - Unexplained gaps in transaction numbering

5. **Control Issues**
   - Missing cash reconciliation
   - No evidence of account reconciliation
   - Transactions outside normal vendor patterns

6. **Policy Issues**
   - Transaction inconsistent with stated policy
   - Cardholder exceeds authorized spending limits
   - Donation used contrary to stated restrictions

## Creating Analysis Summary

Once initial organization is complete, create a summary:

### [FOIA-##] Summary Document

**Title:** FOIA-01: Financial Baseline – Initial Findings

**Structure:**
1. **Documents Received:** Count and types
2. **Organization:** Fund structure, accounts, vendors
3. **Key Findings:** Major expenditure categories, recurring vendors
4. **Observations:** Anything unusual or noteworthy
5. **Gaps:** Missing documents or information
6. **Follow-Up Needed:** Specific clarifications required
7. **Next Steps:** Recommendations for FOIA-02 or follow-ups

## Maintaining the Analysis

### Weekly Task
- Update FOIA Tracking Sheet with any new responses
- Add new transactions to Transaction Review Sheet
- Update Evidence Log
- Note questions or issues for follow-up

### Monthly Task
- Review all transactions received to date
- Create vendor and account summaries
- Prepare summary of findings so far
- Identify patterns or concerns

### When All Responses Received
- Complete all analysis spreadsheets
- Create comprehensive evidence log
- Prepare timeline of key transactions
- Draft summary findings document
- Identify follow-up requests needed

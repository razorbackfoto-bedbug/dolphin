# Getting Started: Hot Spring County Library FOIA Investigation

## What Is This Project?

This is a structured workspace for conducting a comprehensive Freedom of Information Act (FOIA) investigation into the financial records, internal controls, and oversight of the Hot Spring County Public Library.

**Key Point:** This is a neutral, professional inquiry focused on obtaining and analyzing existing public records. It does not accuse anyone of misconduct.

## Submitting the First Round of Requests

### Step 1: Prepare Request Details

Each FOIA request needs:
- Recipient library email address or mailing address
- Your name, email, and phone number
- Sender name (can be yours or a representative)

### Step 2: Edit Request Letters

In each FOIA folder (01 through 05), navigate to:
`Final-Request/FOIA-[#]_Email_Draft.txt`

Replace placeholders:
- `[DATE]` — Today's date
- `[Library Address]` — Hot Spring County Public Library address
- `[NAME]` — Your name
- `[EMAIL]` — Your email
- `[PHONE]` — Your phone number

### Step 3: Send Requests

Email the prepared letter to the library's public records email address.

**When to send:**
- Send all five requests within 1-2 weeks
- Can send all at once or stagger them slightly

**Save everything:**
- Keep copy of sent email
- Note date/time sent
- Save response email when it arrives

### Step 4: Update Tracking Sheet

In `FOIA_Tracking_Sheet.csv`:
- Record request number
- Record date sent
- Record recipient email
- Record sender name

## When Records Arrive

### Step 1: Log the Receipt

## Important Principles

### 1. Keep Public Requests Professional and Neutral
✅ DO:
- Request public records
- Use professional language
- Be specific about what you need
- Follow FOIA procedures

❌ DON'T:
- Mention suspected misconduct
- Use inflammatory language
- Reference other disputes
- Make accusations

### 2. Separate Public and Internal Analysis
✅ DO:
- Keep FOIA requests professional
- Keep analysis notes in Notes/ folders
- Maintain strict separation
- Focus on facts only

❌ DON'T:
- Include suspicions in FOIA requests
- Mix public requests with internal analysis
- Speculate about motives
- Make unsupported accusations

### 3. Focus on Cross-Checking
The goal is to enable verification:
- Receipt → Invoice → Ledger → Bank statement
- Cash log → Deposit slip → Revenue ledger
- Budget → Actual spending
- Policy → Actual practice

### 4. Stop Before Following Up
After all five initial requests are responded to:
- STOP and analyze thoroughly
- Identify specific issues
- Document what you found
- ONLY THEN draft follow-up requests

Do not immediately proceed to FOIA-06, FOIA-07, FOIA-08.

## Red Flags to Track

As you review documents, note these (without assuming misconduct):

- Missing receipts for card charges
- Unusual vendors or purchases
- Deposits delayed several days
- Missing documentation for approvals
- Large purchases without board approval
- Donations with restrictions not honored
- Fund balances that don't reconcile
- Missing statements for certain months
- Duplicate transactions
- Round-dollar amounts suggesting estimates

See `README.md` for the complete list of red flags.

## If You Get Stuck

### Request Not Responded To?
1. Check the response deadline (normally 3 days)
2. Send polite follow-up email
3. If still no response, contact library director

### Records Are Incomplete?
1. Check the FOIA response for exemptions claimed
2. Note which exemptions are listed
3. Determine if you want to appeal or request the non-exempt portions
4. See `Arkansas_FOIA_Quick_Reference.md` for options

### Costs Are Too High?
1. Library must provide itemized estimate before charging more than $25
2. Narrow your request if needed
3. Offer to pay if costs are reasonable

### Not Sure What to Do?
1. Review `Arkansas_FOIA_Quick_Reference.md`
2. Consult the strategic approach guidance
3. Reach out to Arkansas Attorney General for FOIA questions

# FOIA Response Checklist

Use this checklist each time a FOIA response arrives.

---

## When FOIA Response Arrives: Initial Steps

### ☐ Log Receipt
- [ ] Date received: ________________
- [ ] Complete or partial: ________________
- [ ] Any fees charged: ________________
- [ ] Exemptions claimed: ________________
- [ ] Notes: ________________

**Location:** Update `FOIA_Tracking_Sheet.csv`

### ☐ Initial Review
- [ ] Count pages/documents received: ________________
- [ ] Verify it's for the correct FOIA request number
- [ ] Check sender and recipient information
- [ ] Review any cover letter or transmittal note
- [ ] Check for any fees quoted or paid

### ☐ Organize Documents
Create folders if needed:
- [ ] `Incoming-Records/Original-Received/` — Store originals
- [ ] `Incoming-Records/Sorted/` — Create organized copies

Move documents to appropriate folders:
- [ ] Original documents into "Original-Received"
- [ ] Create organized copy in "Sorted"
- [ ] Keep original email/transmittal with documents

### ☐ Create Document Index
For each FOIA response, create an index showing:
- [ ] Document type (ledger, statement, receipt, etc.)
- [ ] Count (how many pages/items)
- [ ] Date range covered
- [ ] Any gaps or missing documents

## FOIA-01 Response: Financial Baseline

When FOIA-01 (Financial Baseline) documents arrive:

### ☐ Organize by Type
Sort documents into:
- [ ] Budgets (by year)
- [ ] General ledgers (by month or period)
- [ ] Expenditure ledgers (by month or period)
- [ ] Revenue ledgers (by month or period)
- [ ] Check registers (by month or period)
- [ ] Financial statements (by period)
- [ ] Bank account list

### ☐ Review for Completeness
- [ ] All years covered (2023 through present)?
- [ ] Budgets for each year?
- [ ] Monthly or periodic ledgers for full period?
- [ ] Check register for full period?
- [ ] Financial statements for all months/quarters/years?
- [ ] Bank account list current?

### ☐ Initial Analysis
- [ ] Create list of all funds/accounts identified
- [ ] List all expenditure categories
- [ ] Identify major recurring vendors
- [ ] Calculate total spending by major category
- [ ] Check if accounts reconcile (ledger balances vs. bank balances)

### ☐ Look for Red Flags
- [ ] Missing months or periods in documents
- [ ] Unexplained account balance changes
- [ ] Accounts not matching budget structure
- [ ] Ledger entries without corresponding bank payments
- [ ] Missing reconciliation documents

### ☐ Update Tracking
**Location:** `FOIA_Tracking_Sheet.csv`
- [ ] Date received: ________________
- [ ] Complete or partial: ________________
- [ ] Any exemptions: ________________
- [ ] Follow-up needed: YES / NO

**Location:** `Evidence_Log.csv`
- [ ] Create entries for key financial documents
- [ ] Record fund names, balances, major accounts

## FOIA-02 Response: Cards, Purchases, Reimbursements

When FOIA-02 documents arrive:

### ☐ Organize by Card/Type
Sort documents into:
- [ ] Credit card statements (by cardholder and month)
- [ ] Debit card statements (by card and month)
- [ ] Receipts (organize by transaction date)
- [ ] Invoices (by vendor and date)
- [ ] Purchase orders (by date)
- [ ] Reimbursement records (by employee/claimant)
- [ ] Approval documentation (by transaction)

### ☐ Create Cardholder List
For each card:
- [ ] Card number/identifier: ________________
- [ ] Cardholder name: ________________
- [ ] Authorization period: ________________
- [ ] Approved spending limit: ________________

### ☐ Match Statements to Receipts
For each credit/debit card:
- [ ] Obtain all statement pages
- [ ] Locate receipts for each transaction
- [ ] Compare amounts (statement vs. receipt)
- [ ] Verify merchant/vendor names match
- [ ] Note any missing receipts
- [ ] Record discrepancies

### ☐ Create Transaction Summary
**Location:** `Transaction_Review_Sheet.csv`

For each transaction:
- [ ] Transaction date
- [ ] Vendor name
- [ ] Description
- [ ] Amount
- [ ] Card/check used
- [ ] Receipt present? Y/N
- [ ] Invoice present? Y/N
- [ ] Ledger entry? Y/N
- [ ] Approval documented? Y/N
- [ ] Any concerns?

### ☐ Look for Red Flags
- [ ] Card charges without receipts
- [ ] Unusual vendors
- [ ] Purchases shipped to residential address
- [ ] Duplicate transactions
- [ ] Round-dollar amounts
- [ ] Missing approval documentation
- [ ] Unauthorized cardholder activity
- [ ] Refunds without matching original purchase

### ☐ Update Tracking
**Location:** `FOIA_Tracking_Sheet.csv`
- [ ] Date received: ________________
- [ ] Complete or partial: ________________
- [ ] Any exemptions: ________________
- [ ] Total transactions reviewed: ________________
- [ ] Follow-up needed: YES / NO

**Location:** `Evidence_Log.csv`
- [ ] Create entries for each significant transaction
- [ ] Record vendor names, amounts, payment methods

## FOIA-03 Response: Cash, Revenue, Deposits

When FOIA-03 documents arrive:

### ☐ Organize by Type
Sort documents into:
- [ ] Daily cash logs (by month)
- [ ] Deposit slips (by date)
- [ ] Receipt books (by sequence)
- [ ] Revenue documentation (by source)
- [ ] Bank statements (to confirm deposits)

### ☐ Create Deposit Schedule
For each deposit:
- [ ] Deposit date: ________________
- [ ] Deposit amount: ________________
- [ ] Corresponding cash log dates: ________________
- [ ] Revenue sources included: ________________
- [ ] Bank statement confirmation: Y/N

### ☐ Reconcile Cash to Deposits
- [ ] Sum daily cash logs for each week/month
- [ ] Match total to deposit slip amount
- [ ] Note timing (same day, next day, delayed)
- [ ] Identify any variances
- [ ] Document any delays or discrepancies

### ☐ Analyze Revenue Sources
- [ ] Identify all revenue sources (fines, fees, donations, etc.)
- [ ] Calculate total by source
- [ ] Note unusual amounts or timing
- [ ] Verify deposits to correct account
- [ ] Check revenue ledger entries

### ☐ Look for Red Flags
- [ ] Cash log total not matching deposit amount
- [ ] Deposits delayed several days after receipts
- [ ] Missing daily cash logs for certain dates
- [ ] Missing deposit slips
- [ ] Unexplained cash shortages or overages
- [ ] Donations with restrictions not documented
- [ ] Unusual revenue sources
- [ ] Deposits without ledger entries

### ☐ Update Tracking
**Location:** `FOIA_Tracking_Sheet.csv`
- [ ] Date received: ________________
- [ ] Complete or partial: ________________
- [ ] Any exemptions: ________________
- [ ] Total deposits reviewed: ________________
- [ ] Follow-up needed: YES / NO

**Location:** `Evidence_Log.csv`
- [ ] Create entries for significant revenue transactions
- [ ] Record revenue sources, amounts, deposit dates

## FOIA-05 Response: Policies, Controls, Oversight

When FOIA-05 documents arrive:

### ☐ Organize by Type
Sort documents into:
- [ ] Purchasing policy
- [ ] Credit/debit card policies
- [ ] Cash handling policy
- [ ] Reimbursement policy
- [ ] Conflict of interest policy
- [ ] Asset control policy
- [ ] Board meeting minutes (all, organized chronologically)
- [ ] Board resolutions
- [ ] Audit reports
- [ ] Other policies

### ☐ Map Approval Authority
From policies received:
- [ ] Who can approve purchases under $X? ________________
- [ ] Who can approve purchases $X-$Y? ________________
- [ ] Who can approve purchases over $Y? ________________
- [ ] Who can approve card expenditures? ________________
- [ ] Who can approve reimbursements? ________________
- [ ] Who can authorize transfers? ________________
- [ ] What documentation is required? ________________

### ☐ Review Board Oversight
- [ ] How often does Board meet? ________________
- [ ] How often are financial reports presented? ________________
- [ ] Does Board approve individual expenditures? Y/N
- [ ] Does Board approve policies? Y/N
- [ ] Are audit findings discussed? Y/N
- [ ] Are corrective actions monitored? Y/N

### ☐ Compare Policy to Practice
Using transaction data from FOIA-02 and FOIA-03:
- [ ] Are transactions approved per policy?
- [ ] Do cardholders follow spending limits?
- [ ] Are reimbursements documented per policy?
- [ ] Are donations handled per policy?
- [ ] Are required approvals obtained?
- [ ] Are there unexplained policy deviations?

### ☐ Look for Red Flags
- [ ] Missing or vague policies
- [ ] Policies not updated in years
- [ ] Approval limits that seem excessive
- [ ] Inadequate documentation requirements
- [ ] No audit or control requirements
- [ ] Conflicts of interest not addressed
- [ ] Board oversight not documented
- [ ] Corrections not made to audit findings

## After All Five Responses Received: Stop and Analyze

### ☐ Complete Analysis
- [ ] All Evidence_Log entries completed
- [ ] All Transaction_Review_Sheet entries completed
- [ ] All Fund reconciliations completed
- [ ] Policy vs. Practice comparison completed
- [ ] Red flags identified and documented

### ☐ Prepare Summary
Create a summary document for each FOIA:
- [ ] FOIA-01 Summary: key accounts, vendors, findings
- [ ] FOIA-02 Summary: cardholder activity, patterns, issues
- [ ] FOIA-03 Summary: revenue reconciliation, findings
- [ ] FOIA-04 Summary: fund reconciliation, findings
- [ ] FOIA-05 Summary: policy gaps, control issues

### ☐ Identify Follow-Up Needs
- [ ] Specific transactions requiring clarification
- [ ] Vendors needing more information
- [ ] Missing documents to request
- [ ] Communications to request for explanation
- [ ] Issues for Friends of the Library records

### ☐ Plan Next Steps
- [ ] Will FOIA-06 be needed? Y/N
- [ ] Will FOIA-07 be needed? Y/N
- [ ] Will FOIA-08 be needed? Y/N
- [ ] Draft follow-up requests (if needed)
- [ ] Set timeline for follow-up

---

**Remember:** Do NOT proceed to FOIA-06, FOIA-07, or FOIA-08 until initial analysis is complete and specific issues are documented.

# FOIA-02: Cards, Purchases, and Reimbursements Analysis Framework

## Purpose

Allow each card or purchasing transaction to be matched against supporting documentation and approvals. Verify that all expenditures are properly documented and approved.

## Reconciliation Strategy

For each credit card statement and debit card statement:

**Match the Statement to:**
1. Itemized receipts (do they exist? do amounts match?)
2. Invoices (is there a formal invoice from the vendor?)
3. General ledger (is the transaction recorded?)
4. Approval documentation (who approved the purchase?)
5. Purchase order (was the purchase authorized in advance?)
6. Board or budget records (do large purchases have board approval?)

## Key Documents to Organize

### Card Statements
- Cardholder name and authorization period
- Card number (partial)
- Statement period and billing date
- Transactions: date, merchant, amount, category
- Beginning and ending balance
- Minimum payment and due date

### Supporting Documentation
- Itemized receipts showing vendor name, transaction date, items purchased, quantities, unit prices, and total
- Invoices from vendors for bulk or recurring purchases
- Delivery documentation (tracking numbers, delivery confirmations, shipping addresses)
- Packing slips and order confirmations

### Approval Documentation
- Purchase authorization forms or approval signatures
- Board meeting minutes documenting approval of major purchases
- Budget information showing approved spending for the category
- Policy documentation showing approval authority for the cardholder

### Reimbursement Records
- Employee or board member expense reports
- Receipts supporting reimbursement claims
- Approval signatures
- Dates of reimbursement and payment method

## What to Track

As documents arrive, create a summary for each transaction:

| Transaction Date | Cardholder/Vendor | Description | Amount | Receipt? | Invoice? | Ledger Entry? | Approval? | Notes |
|---|---|---|---|---|---|---|---|---|

## Red Flags in Card and Purchase Records

Watch for (document but do not assume misconduct):

- Credit card transaction without itemized receipt
- Receipt amount not matching card statement amount
- Itemized receipt showing suspicious items for a public library
- Purchases shipped to residential address rather than library
- Duplicate transactions on same date for similar amounts
- Unusual merchants or vendors
- Purchases inconsistent with library operations
- Missing approval documentation for large purchases
- Reimbursement without supporting receipt
- Refund or credit without matching original purchase
- Round-dollar transactions suggesting possible mischaracterization
- Split purchases that may avoid approval thresholds
- Recurring purchases from same unusual vendor
- Missing card statements for certain months
- Transactions from before or after cardholder's authorization dates

## Analysis Questions

For each card and transaction:

1. **Legitimacy:** Is this a legitimate library expense? Is the vendor appropriate?
2. **Documentation:** Are there itemized receipts? Are amounts accurate?
3. **Approval:** Is there evidence of advance approval? Does it fit the budget?
4. **Accounting:** Is the transaction recorded in the ledger? Does it match the card statement?
5. **Supporting Invoice:** Is there an invoice from the vendor? Does it match the receipt?
6. **Consistency:** Are purchases consistent with past practice for this category?
7. **Timing:** Are reimbursements timely? Is the transaction current?
8. **Authorization:** Does the cardholder have authority to make this purchase? Is it within limits?

## Analysis Checklist

- [ ] All card statements obtained for the period
- [ ] Cardholders and authorization dates identified
- [ ] Card statement amounts totaled by cardholder
- [ ] All cardholders identified in authorization records
- [ ] Itemized receipts obtained for each transaction
- [ ] Amounts reconciled between cards, receipts, and invoices
- [ ] Ledger entries found for each transaction
- [ ] Approval documentation reviewed
- [ ] Unusual transactions flagged
- [ ] Vendor list compiled
- [ ] Reimbursement records analyzed
- [ ] Duplicate transactions reviewed
- [ ] Refund/credit transactions matched to originals

## Follow-Up Items

After analyzing FOIA-02 responses, FOIA-06 may request:
- Specific vendor documentation for questionable purchases
- Missing receipts or invoices for identified transactions
- Cardholder authorization and approval limits
- Duplicate or unusual transactions explained
- Delivery addresses for specific purchases

# Hot Spring County Public Library FOIA Investigation Workspace

## Project Overview

This workspace is designed to organize a comprehensive, phased Freedom of Information Act (FOIA) investigation into the financial records, internal controls, and oversight of the public library serving Hot Spring County.

**Project Goal:** Build a professional, staged FOIA packet that can be submitted by a third party who is not connected to the Friends of the Library or the library itself. The initial requests are neutral, factual, and non-accusatory, designed to obtain and organize public records so that financial activity can be independently reconstructed and cross-checked.

## Key Principles

1. **Neutrality:** Do not mention suspected misconduct, current disputes, or theories about financial wrongdoing
2. **Factual Focus:** Request only existing public records; do not ask the agency to create new reports
3. **Completeness:** Request electronic formats and native files where practical
4. **Transparency:** Require identification of exemptions and written confirmation when no responsive records exist
5. **Cross-Checking:** Design requests to enable verification of transactions across multiple documents

## Legal Framework

All requests are prepared under the **Arkansas Freedom of Information Act**, Ark. Code Ann. § 25-19-101 et seq., with the following standard language:

- Request electronic production where readily available
- Request native spreadsheets or accounting files where practical
- Ask that exempt portions be redacted rather than withholding entire records
- Require identification of specific statutory exemptions for each withholding or redaction
- Ask for written confirmation when no responsive records exist
- Ask the custodian to identify another public custodian if records are held elsewhere
- Request itemized estimate before reproduction costs exceed $25

## Analysis Framework

When records arrive, analyze them without assuming misconduct. Cross-check:

**Transaction Analysis:**
- Credit card statement → Receipt → Invoice → Ledger → Bank payment → Approval → Board record → Asset inventory

**Revenue Analysis:**
- Cash log → Receipt record → Deposit slip → Bank statement → Revenue ledger

**Fund Analysis:**
- Beginning balance + Deposits + Investment earnings - Expenditures - Transfers = Ending balance

## Red Flags to Track

Track these discrepancies (not as proof of misconduct, but as items requiring explanation):

- Card charge without receipt
- Receipt without ledger entry
- Ledger entry without corresponding bank payment
- Payment without documented approval
- Unexplained transfers
- Cash receipts not matching deposits
- Duplicate payments or reimbursements
- Refunds without original purchase
- Purchases shipped to residential address
- Purchases inconsistent with library operations
- Asset purchases missing from inventory
- Disposed assets without documentation
- Reimbursements lacking supporting records
- Donations used contrary to restrictions
- Foundation Fund balances that do not reconcile
- Repeated missing documentation
- Repeated policy exceptions
- Transactions involving employees, board members, or associated businesses
- Recurring purchases from unusual vendors
- Round-dollar transactions
- Split purchases that may avoid approval thresholds
- Missing monthly or reconciliation statements
- Unexplained gaps in receipt numbering
- Deposits delayed for unusual periods
- Board minutes inconsistent with financial records

## Staged Approach

### Stage 1: Financial Baseline (FOIA-01)
Request foundational accounting records to establish all funds, accounts, vendors, and expenditure categories.

### Stage 2: Cards, Purchases, and Reimbursements (FOIA-02)
Request card statements and supporting documentation to trace each transaction.

### Stage 3: Cash, Revenue, and Deposits (FOIA-03)
Request cash handling records to reconcile receipts against deposits.

### Stage 4: Library Foundation Fund (FOIA-04)
Request Foundation Fund records separately to enable independent reconciliation.

### Stage 5: Policies, Controls, and Board Oversight (FOIA-05)
Request policies and board records to identify control environment and approval authorities.

### Later Stages
After analyzing responses to Stages 1–5:
- **Stage 6:** Targeted vendor and transaction follow-ups (FOIA-06)
- **Stage 7:** Targeted communications requests (FOIA-07)
- **Stage 8:** Friends of the Library records (FOIA-08)

## What Not to Include in Public Requests

Do not mention in any FOIA request:
- Suspected financial malfeasance
- The Friends of the Library dispute
- Proposed MOUs or policy changes
- Concerns about defensiveness
- Other libraries or criminal cases
- Internal theories or suspicions

Let the records establish whether any concerns are warranted.

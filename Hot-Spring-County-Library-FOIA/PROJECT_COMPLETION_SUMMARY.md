## Important Principles Embedded in This Project

### 1. **Professionalism and Neutrality**
- All public-facing FOIA requests are professional and neutral
- No accusations, no speculation, no inflammatory language
- Public requests are separated from internal analysis

### 2. **Completeness**
- Requests are designed to enable cross-checking of transactions
- Each request builds on previous ones
- Follow-up requests are only drafted after initial analysis

### 3. **Organization**
- Structured folder system for all documents
- Tracking spreadsheets for accountability
- Clear procedures for handling responses

### 4. **Staged Approach**
- Stage 1: Five foundational requests (complete)
- Pause and analyze
- Stage 2: Follow-up requests (only if issues identified)
- No wild goose chases

### 5. **Sustainability**
- Anyone can step in and understand the project
- No assumptions, all decisions documented
- Clear evidence of process and findings

## Project Philosophy

This workspace is built on the principle that **public records should be available to anyone willing to ask in a professional, organized manner**. It does not assume misconduct, but rather creates a structure to **enable objective analysis** when the records arrive.

The key to success is:
1. **Being professional** — No accusations or speculation
2. **Being organized** — Everything is tracked and cross-referenced
3. **Being thorough** — Complete analysis before drawing conclusions
4. **Being patient** — Let the records speak for themselves
5. **Being persistent** — Follow through on all requests and clarifications
